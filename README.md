# intro-to-py5-and-python

In this assignment, you'll work through a tutorial that introduces you to Python and py5, the tools we'll use for most of this course. In this initial tutorial, we'll be coding in Google Colab to make setup efficient.

## 1. Work through the tutorial

Open **`tutorial.md`** and read through it from beginning to end. This is where you will access the basic content knowledge for this assignment.

As you go, try out the code examples in a file called **`playground`**. Feel free to change things, experiment, and see what happens. Playing around is how you'll actually learn something from this assignment!

## 2. Complete the challenge task

At the end of the tutorial, you'll find a challenge. Complete it by writing your code in a file called **`task_rainbow`**.

> Note the rubric on Canvas: To earn full credit, you need to **add your own twist** to the sketch after you have the basics working.

## 3. Submit your work on Canvas

When you're done, make sure that your `task_rainbow` Colab project is viewable by sberman@punahou.edu. Then, submit the link to Canvas.
