# intro-to-py5-and-python

In this assignment, you'll work through a tutorial that introduces you to Python and py5, the tools we'll use for most of this course.

## 1. Work through the tutorial

Open **`tutorial.md`** and read through it from beginning to end. This is where you will access the basic content knowledge for this assignment.

As you go, try out the code examples in **`playground.py`**. Feel free to change things, experiment, and see what happens. Playing around is how you'll actually learn something from this assignment!

## 2. Complete the challenge task

At the end of the tutorial, you'll find a challenge. Complete it by writing your code in **`task_rainbow.py`**.

> Note the rubric on Canvas: To earn full credit, you need to **add your own twist** to the sketch after you have the basics working.

## 3. Save your progress to GitHub

**Commit and push your work often** as you work through the assignment. This lets me see your progress, not just your finished code.

You do not need to submit anything on Canvas. Your work on GitHub is your submission.
